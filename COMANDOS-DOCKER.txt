------------------------------------------------------------
   COMANDOS DEL DIA A DIA   (ejecutar en /mnt/c/Kanbana)
------------------------------------------------------------

  Arrancar el proyecto (segundo plano):
        docker compose up -d

  Ver si los 4 contenedores estan arriba:
        docker compose ps

  Detener (conserva los datos):
        docker compose down

  Pausar sin eliminar:
        docker compose stop

  APLICAR CAMBIOS DE CODIGO (reconstruir):
        docker compose up --build -d

  Ver logs del backend (Ctrl+C para salir):
        docker compose logs -f backend

  Ver logs de todo:
        docker compose logs -f

------------------------------------------------------------
   MODO DESARROLLO (hot-reload, SIN --build cada vez)
------------------------------------------------------------

  Monta tu codigo y recarga solo al guardar (nest watch + vite HMR).
  Ideal mientras programas; no tienes que reconstruir por cada cambio.

  1. Detener produccion (libera los puertos 3000 y 5173):
        cd /mnt/c/Kanbana
        docker compose down

  2. Arrancar en modo desarrollo:
        docker compose -f docker-compose.dev.yml up

     -> Editas un archivo y se refleja solo.
     -> Frontend: http://localhost:5173   Backend: http://localhost:3000
     -> La 1a vez instala dependencias dentro del contenedor (tarda);
        las siguientes veces es rapido.

  3. Detener el modo desarrollo:
        docker compose -f docker-compose.dev.yml down

  OJO: si agregas una dependencia (cambias package.json), reinicia el servicio:
        docker compose -f docker-compose.dev.yml restart backend
        docker compose -f docker-compose.dev.yml restart frontend

  Resumen rapido:
     DEV (hot-reload):  docker compose -f docker-compose.dev.yml up
     PRODUCCION:        docker compose up --build -d

------------------------------------------------------------
   SI ALGO FALLA
------------------------------------------------------------

  "no configuration file provided"
        -> no estas en la carpeta:   cd /mnt/c/Kanbana

  "up: command not found"
        -> falto el prefijo:         docker compose up -d

  "sudo esta deshabilitado en este equipo"
        -> ejecutaste algo de Linux en PowerShell.
           Entra a Ubuntu (wsl) y reintenta ahi.

  "Cannot connect to the Docker daemon"
        -> arranca el motor:         sudo service docker start

  "port is already allocated" (puerto 3000 o 5173 ocupado)
        -> en PowerShell:
           Get-NetTCPConnection -LocalPort 3000 -State Listen | Select OwningProcess
           Stop-Process -Id <PID> -Force

  Cambie codigo pero la app sigue igual
        -> falto --build:            docker compose up --build -d

  El backend dice "ECONNREFUSED ... Retrying" al arrancar
        -> NORMAL la primera vez (MySQL inicializando). Espera; conecta solo.

  Empezar de cero (BORRA TODOS LOS DATOS):
        docker compose down -v
        docker compose up --build -d

  Liberar espacio (imagenes viejas):
        docker system prune -a
